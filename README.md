# 大乱闘ファイターズ（スマブラ風 2D対戦ゲーム）

タブレット（キーボード無し）で遊べる、ブラウザ用の2D対戦アクションです。`index.html` 1ファイルで動作します。

## 遊び方
- 左下：**移動スティック**（移動・技の方向入力）
- 右下：ボタン
  - **攻撃A**：地上は弱・横強・上強・下強（ダッシュ中はダッシュ攻撃）、空中は空N・前・後・上・下
  - **スマッシュ**：横・上・下スマッシュ（スティックの方向で変化）
  - **必殺技B**：スティックなし=NB / 横=横B / 上=上B / 下=下B
  - **つかみ / シールド / ジャンプ（空中ジャンプ1回）**
  - **切りふだ**：ゲージが満タンで使用可能
- ダメージ%が高いほど遠くに飛びます。画面外に出るとストック減少、ストック0で負け。

## 公開方法（GitHub Pages）
1. リポジトリを作成し、`index.html` と `README.md` をアップロード
2. Settings → Pages → Branch: `main` / root を選択
3. 表示されたURLをタブレットで開く（「ホーム画面に追加」で全画面）

## キャラクターの追加方法
`index.html` 内の `CH` 配列にオブジェクトを追加します。技の種類は `proj`（飛び道具）`dash`（突進）`up`（復帰）`ref`（反射）`ctr`（カウンター）`beam`（切りふだ）`mel`（近接）から選べます。通常技は `ov` で威力・角度などを上書きできます。

## 追加メモ
- スネーク・ディディーコング・ゼロスーツサムス・ポケモントレーナー3匹は、一部の技名を記憶ベースで入れています（要確認）。ワリオ・アイクは技名を確認できず未収録です。
- エフェクト: ヒットストップ、衝撃波リング、放射状スパーク、残像、加算発光、ダメージ数字、切りふだのカットイン、撃墜フラッシュ、自動ズームカメラ。
- ワリオ追加（下Bの技名「おなら」は仮名・要確認）。スネークの切りふだは「援護射撃」に修正。アイクは技名未確認のため未収録。
- 溜め技（弓・チャージショット・波導弾など）は溜め中に光の粒とリングが集まる演出。画面端に周辺減光を追加。

## プレイヤー認識・オンライン対戦
- **プレイヤー認識**: メニューで名前（8文字まで）を入力すると、端末に保存されます（localStorage）。初回に自動でプレイヤーIDが発行され、CPU戦・オンラインの勝敗、対戦相手ごとの通算成績（IDで同一人物を判別）を記録します。ゲーム中は頭上に名前を表示します。
- **オンライン対戦（1対1）**: 「部屋を作る」で4桁の部屋番号が出るので、相手が「部屋に入る」で番号を入力します（画面上のテンキー）。通信はPeerJS（WebRTC）で、サーバー不要です。
- 方式: 主催者側が戦闘を計算し、参加者は操作を送って映像を受け取ります。参加者は主催者との通信遅延ぶん操作が遅れます。
- 制限: 公開の仲介サーバー(PeerJS Cloud)に依存し、TURNサーバーは使っていないため、厳しいネットワーク（会社・学校のWi-Fiなど）では接続できないことがあります。試合終了で接続は切れます（再戦は部屋を作り直し）。

## 演出（v2）
- **試合開始演出**: 「READY to FIGHT!」→ 各ファイターのネームカード → キャラごとに違う登場アニメ（落下/ワープ/せり上がり/スライド/回転落下）→ 3・2・1・GO!
- **最後の切りふだ**: 暗転して背景がキャラ色に染まり、放射状の集中線の中で、キャラの大きなカットインと技名が登場。発動後は画面全体がキャラ色に染まります。
- **必殺技**: 発動時にキャラ色のオーラ・衝撃リング・技名ポップアップ。
- **キャラごとの見た目の違い**: 色から属性（炎・雷・葉・氷・水・闇・星・光）を判定し、粒子の形・飛び道具の形を変えています。さらにキャラ名から決まる値で、斬撃の弧の本数・角度・揺れ方を変えています。
- キャラ選択画面に各キャラの顔アイコンを表示。

## 切りふだ専用シーン（v3）
切りふだを使うと、カットイン（約1秒）のあと、キャラごとに決めた専用シーン（約1.4秒）が流れてから戦闘に戻ります。シーンは14種類で、全キャラに割り当て済みです。
炎の大波（マリオ・リザードン）/ 巨大ビーム（リンク・サムス・ピットほか）/ 連続ラッシュ（ドンキー・ケン・テリーほか）/ 連続斬り（マルス・クラウドほか）/ 流星群（ネス・リュカ・セフィロス）/ 魔法陣と召喚（ベヨネッタ・パルテナほか）/ 渦（ミュウツー・ルカリオほか）/ 紋章（ゼルダ・ソラ・シモンほか）/ 高速疾走（ファルコン・フォックス・ソニックほか）/ 落雷（ピカチュウ・ルフレ）/ 大津波（ゲッコウガ・インクリングほか）/ 連続爆発（スネーク・デデデほか）/ 巨大化（クッパ・ガノン・ワリオほか）/ 星の雨（カービィ・ヨッシーほか）。
割り当ては `index.html` の `SCT` 表で変更できます。
- 切りふだシーンには、そのキャラ自身の分身が3〜7体、キャラごとに違う配置（周回・横断・落下・渦巻き）で登場します（ロックマンスペシャルやWii Fitのような演出）。
- **キャラ固有モチーフ**: 切りふだシーンの中に、キャラごとのモチーフ（キノコ・トライフォース・モンスターボール・バナナ・ハート・ドクロ・音符・魚・葉・歯車・目・翼・リング・矢・卵など18種）が降り注ぎます。`MT` 表で変更できます。

## オンライン（v4）
- **ランダムマッチ**: メニューの「ランダムマッチ」を押すだけで、同じ瞬間に押した人と自動で対戦します。待機中の人がいればすぐ参加、いなければ待機側になり、ルーム番号（0001〜1000）の若い順に探します（待機中は数秒おきに若い番号の待機者を探すので、同時に押しても出会えます）。
- 接続の安定化: PeerJSライブラリを3つのCDNから順に読み込み、STUN/TURNサーバーを設定。部屋番号が重複したら自動で振り直し、接続できないときは原因を画面に表示します。
- 注意: 通信は公開の仲介サーバー(PeerJS Cloud)と公開TURNに依存します。claude.aiのプレビュー内では通信が制限されることがあるので、**GitHub Pagesなどで公開したURLで開いてください**。

## 作り直し進行表（順番どおり・専用実装）
各キャラに専用の描画、通常技（多段ヒット・突進・埋め・メテオ）、必殺技、切りふだを実装し、`CUS` 表に登録します。
- [x] マリオ: 帽子・Mの印・口ひげ・つなぎ・白手袋の専用描画。弱3段、上強の連続ヒット、下スマの2段、空下の連続キック。ポンプは溜めるほど強く押し出す。切りふだは大きな炎を斜めと水平の2発、貫通しながら多段ヒット。
- [x] ドンキーコング: 大柄で腕の長い専用描画（ネクタイ付き）。ジャイアントパンチは溜め式（シールドで溜めを保持して後で撃てる）、ヘッドバットとハンドスラップは地上の相手を埋める、スピニングコングは地上で多段前進・空中で上昇。切りふだは相手を捕まえて連打するロック技。
- [x] リンク: 緑の帽子・ブロンドの髪・背中の盾・剣の専用描画。ブーメランは上下に狙える、リモコンバクダンは時間または下Bの再入力で起爆し自分の復帰にも使える、回転斬りは地上で多段・空中で上昇。切りふだは照準を合わせてから1本の大矢を放ち、当たった場所で大爆発。
- [x] サムス: オレンジの装甲・緑のバイザー・大きな肩当て・右腕の大砲の専用描画。弱は3段、空前・空N・空上は多段ヒットの連続射撃、下スマは前後同時、上スマは2段。チャージショットは最大120Fまで溜められ、シールドで溜めを保持して後から即撃ち。ミサイルは通常=追尾、Bを押しっぱなし=スーパーミサイル（高威力・直進）。スクリューアタックは多段ヒットで上昇。ボムは置いて爆発し、自分が近くにいると上へ跳べる（ボムジャンプ）。切りふだのゼロレーザーは、溜めてから、スティックの上下で向きを動かせるレーザー（多段ヒット、最後に撃ち上げ）。
- [x] ダークサムス: 暗紫の装甲とシアンの発光の専用描画。サムスと同系統の技で、チャージショットがより大きく溜まる。
- [x] カービィ: すいこみ→星で攻撃＋コピー（NBがコピー元に変わり帽子の色も変わる）、ハンマー、ファイナルカッター（上昇→静止→急降下→衝撃波）、ストーン（無敵・空中でメテオ）。切りふだはウルトラソードの3連撃。丸い体の専用描画。
- [x] ガノンドロフ: 魔人拳（溜め中に振り向くと反転・強化）、炎獄握（地上は叩きつけ・空中は急降下）、雷神掌（つかみ上昇→爆発）。魔獣ガノンは四足の魔獣へ変身して突進。全通常技が重く発生が遅い。
- [x] Mr.ゲーム&ウォッチ: 平面の黒いシルエット・2コマ動作。ジャッジは1〜9の運（凍結・炎・回復・撃墜級など）、ファイアはトランポリン＋パラシュート降下、オイルパニックは吸収→放出。通常技は消火器・旗・マンホール・松明・魚・爆弾・鍵など。切りふだは触手で引き寄せる。
- [x] ヨッシー: 舌で卵に封じる、放物線の卵投げ（復帰不可）、ヒップドロップ（着地の衝撃波）、切りふだは複数のヨッシーが駆け抜ける。
- [x] フォックス: 溜めてから向きを決めるファイアフォックス、切りふだはロックオン6連射。高速多段ヒットの通常技。
- [x] ピカチュウ: 溜めるロケットずつき、2回向きを変えるでんこうせっか、少し前方に落ちるかみなり。通常技は尻尾と電撃。（切りふだは共通のorb方式のまま）
- [x] マリオ（仕上げ）: 通常B/横B/上Bも専用化。マントは空中で落下を遅らせ、飛び道具を反射して相手の向きを反転。上Bは多段ヒット（コイン）。
- [x] ルイージ: 背の高い専用描画（掃除機を背負う）。ファイアボールは跳ねない、ルイージロケットは溜めと1/8の暴発、上Bは先端だけ高威力、サイクロンはB連打で上昇、切りふだはオバキューム（吸い込み→衝撃）。
- [x] ネス: PKフラッシュとPKサンダーはスティックで操作（操作中は動けない）、PKサンダーを自分に当てると高速で飛ぶ復帰、サイマグネットは吸収回復、前スマッシュのバットは飛び道具を打ち返す、PKスターストームは降る位置を操作できる。
- [x] キャプテン・ファルコン: 空前の膝は出始めの3フレームだけ強い、ファルコンパンチは溜めて反転可能、横Bは地上=アッパー・空中=叩きつけ、ブルーファルコンは愛機で突っ込む。
- [x] プリン: 丸い体、うたうで眠らせる、ねむるは超高リスクの撃墜技、おおきくなるで3.3倍に膨らんで押し出す。
- [x] ピーチ: ドレスと王冠の専用描画。空中で浮遊（約70F）、キノピオが攻撃を受け止めて胞子で動きを止める、傘で多段ヒットしながら上昇して降下、野菜は複数の種類（ボム兵・ビームソード含む）、前スマはクラブ/フライパン/ラケットがランダム、切りふだは眠らせて回復。
- [x] クッパ: 1.35倍の巨体・甲羅のトゲの専用描画。9%未満ではひるまない、クッパブレスは燃料式の連射、ダイビングプレスは掴んで跳んで叩きつけ、スピニングシェル、クッパドロップ、切りふだはギガクッパ化して強烈な一撃。
- [ ] 次: アイスクライマー、シーク、ゼルダ、マルス、ルキナ … （ダークサムスは通常技の再設計が残り）


## ルーム番号（0001〜1000）
- **ルームを作成**: 人のいない、いちばん若い番号のルームに入り、その番号を画面に表示します。
- **ルームに参加**: 入力した番号のルームに入ります（0001〜1000以外は受け付けません。誰もいない/満員の場合はその旨を表示）。
- **クイックマッチ**: 1人で待っているルームがあればそこに参加。なければ新しいルーム（空いている最小番号）を作って待機します。待機中も、より若い番号の待機者を数秒おきに探します。
- 通信方式はPeerJS（WebRTC）です。

## 品質管理（v5）
- `CHARACTER_RESEARCH/` … キャラ別の研究・設計資料（出典の状態を明記）。
- `QUALITY_REPORT.md` … 品質評価表（`node tools/quality_report.mjs` で再生成）。専用実装済みと未完成を自動集計し、他キャラと同じ構造の技の数も出します。
- **モーションラボ**（メニュー） … 選んだ2キャラに同じ種類の技を並べて繰り返し再生（モーション比較テスト）。「エフェクトなし」（光・粒子・斬撃を消して当たり判定の枠のみ）と「シルエット」（真っ黒表示）で、エフェクトに頼らず動きの違いを確認できます。
- **画質**（メニュー）: 低/中/高/最高。解像度・粒子量・影・周辺減光・残像が変わります。
- バックアップ: `backup/` に今回の改修前のファイルを保存。
